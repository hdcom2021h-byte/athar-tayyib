# منصة أثر طيّب — موقع مستقل

موقع عربي تفاعلي ثابت، دون قاعدة بيانات أو حسابات أو مكتبات خارجية.

## التشغيل
افتحي `index.html` في متصفح حديث (Chrome أو Safari أو Edge). تعمل المعاينة وتصميم البطاقات وتغيير الألوان ونسخ النصوص دون إنترنت. تتطلب مشاركة واتساب اتصالًا بالإنترنت وتطبيقًا أو متصفحًا يدعم واتساب.

## نشر اختياري برابط عام
ارفعي مجلد الموقع على خدمة استضافة مواقع ثابتة مثل Render Static Site أو Cloudflare Pages. حددي مجلد النشر على أنه المجلد الذي يحتوي `index.html`. لا يحتاج الموقع إلى خادم أو مفاتيح API.

## وظائف المنصة
- الرئيسية: أربع بطاقات للتنقل إلى خدمات المنصة.
- تصميم بطاقات شكر وتهنئة وتعاون وترحيب، بثلاث هويات لونية، مع معاينة فورية.
- تنزيل PNG، مشاركة البطاقة عندما يدعم المتصفح مشاركة الملفات، نسخ النص، فتح واتساب برسالة، والطباعة.
- إرسال أفكار ومواقف إيجابية عبر واتساب أو نسخها.
- استبيان أثر المبادرة وإرسال إجاباته عبر واتساب أو نسخها.

## حدود مهمة
- زر واتساب يجهز الرسالة ويفتح واتساب؛ تختار المستخدمة المستلمة وتؤكد الإرسال بنفسها.
- مشاركة صورة البطاقة مباشرة تعتمد على دعم نظام التشغيل والمتصفح؛ في غير ذلك تُحمّل الصورة ثم تُرفق يدويًا.
- لا يوجد تجميع مركزي للمشاركات أو تقارير إحصائية؛ يتطلب ذلك خدمة تخزين خارجية.
- بعض المتصفحات تمنع النوافذ المنبثقة للطباعة أو تقيد مشاركة الملفات عند فتح HTML محليًا. النشر عبر HTTPS يحسن دعم هذه المزايا.
